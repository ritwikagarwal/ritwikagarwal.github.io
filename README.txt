RITWIK PERSONAL WEBSITE

This is a simple three-page HTML and CSS website.
No installation or build tools are required.

FILES

- index.html: Home and about page
- projects.html: Project listing
- cv.html: Embedded CV page
- menu.html: Shared navigation menu
- myStyles.css: All site styles
- image/: Portrait, research image, and CV PDF

OPEN IN VS CODE

1. Unzip the folder.
2. Open Visual Studio Code.
3. Choose File > Open Folder.
4. Select the ritwik-personal-site folder.
5. Open index.html in a browser.

For the best local preview, you can use the Live Server extension in VS Code.

EASY EDITS

- Change page text inside the HTML files.
- Change colors at the top of myStyles.css.
- Replace image/ritwik-portrait.jpg with your real headshot.
  Keep the same filename to avoid changing the HTML.
- Replace image/cv.pdf when your CV changes.
  Keep the same filename to avoid changing the HTML.

IMAGE NOTE

The current profile picture is an illustrated placeholder. Replace it with a real headshot before final submission if your instructor expects a photograph.
